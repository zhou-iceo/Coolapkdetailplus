# CoolapkDetailPlus (酷安详情页增强插件)

这是一个基于 **LSPosed (LibXposed / YukiHookAPI)** 的 Xposed 模块，专为酷安客户端设计，旨在为酷安的内容详情页（如 `FeedDetailActivityV8`）提供强大、轻量的**页内文本检索与精准滚动定位**增强功能。

---

## 核心特性

- **无缝菜单注入**：
  - 在详情页顶部选项菜单 (`OptionsMenu`) 中自动增加【查找】操作项；
  - 在底栏长按弹窗/更多操作菜单中智能适配注入【查找】按键，风格与酷安原生 UI 协调一致。
- **优雅悬浮查找交互**：
  - 现代化圆角卡片式悬浮搜索栏，支持单手操作；
  - 实时关键字检索并呈现匹配计数（如 `1/12`）；
  - 醒目高亮区分当前匹配项（橙底白字）与其他匹配项（黄底黑字）。
- **行级精准滚动定位（近期重点修复）**：
  - 支持点击“上一个”（▲）和“下一个”（▼）按钮平滑滚动定位到准确位置；
  - 支持同一个长帖/长文本 `TextView` 内多处匹配的行级精确定位（通过 `TextView.layout` 行像素计算）；
  - 跨 ClassLoader 安全穿透，完美适配酷安的 `RecyclerView`、`NestedScrollView`、`ScrollView` 等滚动容器；
  - 自动根据当前顶部悬浮栏的屏幕高度动态避让，确保高亮行始终舒适呈现在搜索栏下方；
  - 支持列表滑动回收后离屏项目的智能恢复定位。
- **配套模块管理与实时日志**：
  - 使用 Jetpack Compose 开发的原生模块 App；
  - 实时显示 LSPosed 模块激活状态；
  - 提供实时日志控制台，可在宿主酷安运行时捕获插件的关键检索与滚动定位步骤。

### v1.0.3 (补全 SearchEngine 引擎源码与精准滚动集成)
1. **完整集成 SearchEngine 检索引擎源码**：
   - 补全并提交 `SearchEngine.kt` 源码文件，包含行级偏移绝对 Y 轴计算、跨 ClassLoader 滚动容器探测以及离屏项恢复能力；
   - 保证检索悬浮栏与滚动引擎在工程中开箱即用并顺利通过编译。

### v1.0.2 (功能菜单布局与样式高保真对齐)
1. **菜单【查找】按钮按序水平排列至行尾**：
   - 解决此前在酷安内容详情页的长按/功能菜单（BottomSheet）中，【查找】按钮被错误插入为独立全宽横条的问题；
   - 针对第一行横向 `RecyclerView` 容器机制，采用动态横向容器包装方案，将【查找】按钮无缝追加在 `复制 - 收藏 - 编辑历史 - 举报` 既有按钮的最后，实现水平平铺；
2. **像素级视觉样式对齐（Pixel-Perfect）**：
   - **矢量图标重构**：弃用系统 emoji 放大镜，使用纯代码绘制的矢量 `SearchIconDrawable`，线条平滑圆润，且颜色自动跟随宿主当前主题（浅色/深色模式）自适应；
   - **背景与规格克隆**：动态克隆宿主原生按钮的灰色圆形背景 Drawable（支持日间/夜间模式自动切换）与尺寸规格；
   - **文本与交互对齐**：字号、字体、文字颜色与顶部间距 100% 同步参考项 TextView，并添加系统原生点击水波纹按压反馈；
3. **分层兼容策略**：
   - 优先支持酷安主流的横向 `RecyclerView` 水平包装注入；
   - 兼容水平 `LinearLayout` 直接追加并均分权重；
   - 保留全宽横条作为最终兜底，确保在任何未知定制视图下功能绝不丢失。

### v1.0.1 (精准滚动定位修复)
1. **修复点击“上一个/下一个”按钮无法精准滚动定位的问题**：
   - 彻底重构 `SearchEngine` 滚动计算模型，从单纯的控件顶部定位升级为 `TextView` 内部的**精确文本行级绝对 Y 轴像素定位**；
   - 解决同一长贴/文章内包含多个匹配词时由于 Y 坐标不变导致页面不发生滚动的严重缺陷；
2. **解决跨 ClassLoader 导致的容器识别失效问题**：
   - 针对 LSPosed 环境下 ModuleClassLoader 与 HostClassLoader 隔离导致的 `instanceof RecyclerView` 失效，引入基于类继承链反射的安全容器探测机制；
3. **动态避让悬浮检索栏**：
   - 动态获取当前悬浮检索栏在屏幕中的下沿位置，并在下方留出安全呼吸间距，彻底消除目标高亮文字被顶部搜索栏遮挡的情况；
4. **增强关键步骤日志输出**：
   - 在日志中输出每次滚动的目标行、容器类型与滑动距离 `dy`，便于排查与验证。

## 编译与打包

本工程使用 Gradle 8.9 + AGP 8.9.1 构建。

### 编译 Debug APK
```bash
./gradlew.bat assembleDebug
```
产物位置：
`app/build/outputs/apk/debug/app-debug.apk`

### 编译 Release APK
```bash
./gradlew.bat assembleRelease
```
产物位置：
`app/build/outputs/apk/release/app-release-unsigned.apk`
